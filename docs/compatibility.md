# Compatibility

Targets: Codex, SealSeek and WorkBuddy on macOS and Windows. Lifecycle adapters are implemented; complete host application flows are not claimed as tested. macOS CLI/package tests and CI results belong to the exact release commit.

Package tests cover managed copy/link installation, repeat installation, hashes, edited or occupied targets, customized metadata, locked-directory recovery, failed-update backups and UTF-8. CI runs on macOS/Windows with Node 22/24. These are package tests, not proof of Agent-native vision or browser integration.

Local 1688 service authentication previously returned AUTH_REQUIRED (invalid/expired signature). Configuration detection does not prove remote authorization. Real sourcing QA requires current user authorization. SealSeek gateway was unavailable during the earlier host check. WorkBuddy could discover the previous mixed Skill; the split application flow still needs real host verification.

Skill clean-context regression has not been requested. Historical source tests are preserved as development evidence, not fresh host acceptance.

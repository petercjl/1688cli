# 方法更新记录

## 2026-09-29 · 主图逐图打标与视觉聚类

- 用户确认电商标题不可作为款式分类事实来源；款式分类改为商品主图优先。
- 固定每批最多 10 张主图并发分析，每张图单独保存可见标签、依据、置信度和判断状态。
- 全部逐图打标完成后才做相似性聚类；每个商品只进入一个主要视觉款式类别，多维属性保留为视觉标签。
- 标题、SKU 和搜索词只在聚类后用于命名、搜索扩展与图文冲突提示，不得替代视觉判断。

## 2026-09-28 · 高覆盖找货与比选

- 用户确认目标是尽量多地召回相关链接，供价格和供应商筛选；不以代表款数量作为完成条件。
- 全部查询结果按商品 ID 归并，保留多轮来源与 SKU/价格观察；商品可属于多个类别，唯一链接总数只计一次。
- 新交付契约为 `2.0.0`，包含完整商品库、逐条相关性、覆盖边界及价格/商家初筛视图。

## 2026-09-28 · HTML 交付

- 用户确认找货结果以分类 HTML 呈现，每个商品链接配网络图片和基础信息。
- 固定“证据 JSON → 分类 ViewModel → 共享 `commerce-ui` 模板包 HTML”的交付边界。

## 2026-09-28

- 确认以“用户是否提供参考图”为一级路由；文字需求走探索，图片需求走精确找款。
- 两个分支共用查询证据、去重、停止和交付主线。
- 多张参考图逐张保留来源，避免把不同商品误并为一个目标。

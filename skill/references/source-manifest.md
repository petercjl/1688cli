# 方法来源与维护边界

编译日期：2026-09-29。覆盖状态：`partial`，采用混合模式（主线硬约束 + 按需加载的找货判断）。

来源类型：`W/U/E/A`，分别表示可追溯知识、用户确认方法、已验证执行证据和待验证的 Agent 建议。

| 来源 | 已吸收的方法 | 适用边界 |
| --- | --- | --- |
| `U` 用户确认的找货经验 | 宽词先看款式；按观察到的类别细化词；合适的商品图可继续图搜；有参考图走精确路线 | 两种一级输入模式与迭代搜索 |
| `U` 用户确认的交付方式 | 分类 HTML、每个商品链接配图片及基础信息，商品图片使用网络 URL | 找货报告交付；图片可用性受网络和源站影响 |
| `U` 用户确认的高覆盖目标 | 尽量找出相关搜索路线下的商品链接，按唯一商品归并，允许跨类别展示；用于价格和供应商筛选 | 当前底层无已验证分页，覆盖率须保留限制说明 |
| `U` 用户确认的视觉分类方法 | 电商标题不可作为款式事实；每批最多 10 张主图并发逐图打标，完成后按可见结构和标签做相似性聚类 | 探索模式的款式分类；材质、性能和图外信息仍须核验 |
| `W` 1688 采购与分销 Agent 能力地图、意图路由、执行安全契约 | 区分商品搜索与供应商查询；平台数据与分析分层；凭证和错误边界 | 2026-07-16 来源快照，仅用于方法，不作为当前 CLI 参数真相 |
| `W` 供应商开发与分级管理 | 建候选池、核验资质/样品/交付；不以挂牌价格替代谈判结果 | 人工接洽阶段的检查问题 |
| `E` 本包 1688cli 查询与源码 | 关键词、图片 URL、供应商查询可返回结构化数据；返回的商品图片 URL 可用于新一轮图搜 | 当前本地开发版，其他机器和 SealSeek 运行尚待验证 |
| `E` 已安装 `compact-commerce-ui` / `commerce-ui` 契约 | `compact-workbench@1.0` 支持独立商品分类视图、产品图卡和经授权的 HTTPS 外链图片 | 运行时须检查当前版本与模板；其他 Agent 环境待验证 |
| `A` 本 Skill 输出与停止设计 | 款式地图、逐图对照清单、查询轨迹、边际新发现停止判断 | 待真实任务与用户审阅后调整 |

关键空缺：当前官方商品搜索是否支持真正的分页与平台总量；不同 Agent 对网络主图的并发视觉读取能力与稳定性；视觉标签和聚类的一致性阈值；图片相似度与真实同款的关系；品类特有的质量/合规条件；商家最终报价和供货能力。输出需保留这些待验证项。

当 CLI 字段/认证方式、用户确认的找货方法、图片输入适配或候选评估标准发生实质变化时，重新编译相关主题与路由，并测试无图、单图、多图任务。此文件不应成为运行时的默认读取内容。
